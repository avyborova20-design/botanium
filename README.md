## Тематика проекта
Информационный веб-ресурс, посвященный домашним и садовым цветам. Сайт представляет собой подробную базу знаний по уходу за растениями для начинающих и опытных цветоводов.

## Цели и задачи
* Цель: Создать удобную площадку, где пользователь сможет быстро найти все правила содержания конкретного цветка в одном месте.
* Задачи:
    1. Разработать удобную навигацию по видам растений.
    2. Создать наглядные инструкции по пересадке и поливу.
    3. Подготовить календарь подкормок (витаминов) для разных сезонов.
* Связь с контентом: Тематические блоки, таблицы с графиком полива и иллюстрированные карточки товаров помогут пользователю не гуглить информацию на разных сайтах, а получить готовый план действий.

## Целевая аудитория
* Типичный пользователь: Женщины и мужчины 18–65 лет, имеющие комнатные растения или дачный участок.
* Потребности: Поиск информации о том, почему желтеют листья, как правильно подобрать грунт для пересадки и какие удобрения нужны весной.

## Содержание и структура сайта
* Основные разделы: 
    * Главная (популярные растения).
    * Каталог цветов (алфавитный указатель).
    * Блог (статьи о пересадке и витаминах).
    * Календарь садовода.
* Организация контента: Информация будет разбита на карточки: «Полив», «Свет», «Пересадка», «Подкормка», чтобы пользователю было легко сканировать текст глазами.
